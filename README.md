# CanvasGPT

CanvasGPT converts Canvas assignments into editable checklists and personalized study schedules.

## Local setup

1. Create a virtual environment with `python -m venv .venv`.
2. Activate it with `source .venv/Scripts/activate`.
3. Install packages with `python -m pip install -r requirements.txt`.
4. Run migrations with `python manage.py migrate`.
5. Start the server with `python manage.py runserver`.
6. Open http://127.0.0.1:8000/.
